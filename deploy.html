Run your own

From nothing to a service on your own Windows machine that an agent can ask what you were just doing. These steps were followed for real on Windows 11, and where something went wrong, the page says so. There is no server step: Athena is meant to run where you work, and nowhere else.

The code is not public yet. It lives in a folder on its owner's machine and has not been published. Everything below describes exactly how it is installed and run, and will work as written once a repository address appears in step 1. Until then this page is a description, not something you can follow.

What you will need

ThingWhat it is for
Windows 11 and Python 3.13The signals are Windows' own. It was built and tested on Python 3.13.Required
About 300 MB of diskThe Python packages, a 30 MB embedding model, and two weeks of records at roughly 2 to 3 MB a working day.Required
A model key, or a model on your machineOnly for the pass that infers goals, commitments and style. Everything else runs without one.Optional
1 GB of memory to spareOnly if you turn on the classifier that withholds text written to steer an agent.Optional

What it costs to run. No money as installed: only code and one small local model run, and nothing leaves the machine. Measured here: 0.7% of one processor core over an 85-minute run before search indexing was added, 180 MB of memory with search, and about 250 KB of disk per hour of use. The optional model pass is estimated at 3 to 8 cents a run on a large model and under a cent on a small one, at most once in six hours; it has not been run, so that is an estimate from token counts.

1

Get the code and install it

Get the code from the project's repository (its address will appear here when it is published) and open a terminal in its folder.

Windows (Command Prompt or PowerShell)
setup.cmd

This makes a Python environment in %USERPROFILE%\.athena\venv and installs the packages. The environment is deliberately outside the project folder, so the project can live in a synced folder without thousands of package files being synced.

What went wrong here. The first environment was made under %LOCALAPPDATA% from inside a packaged desktop app. Windows silently redirects such an app's new files there to a private copy, so an ordinary terminal could not see the environment at the path that had been asked for. A folder directly under your user profile is not redirected.

2

Start it

athena.cmd run

It prints where the data is kept and the address it serves, http://127.0.0.1:8377/mcp, and starts recording. The first search downloads the embedding model once.

The data folder is %USERPROFILE%\.athena\data. To put it elsewhere set ATHENA_HOME. The program refuses to start if that folder is inside OneDrive, Dropbox, Google Drive or iCloud: a record of your screen should not be copied to someone else's computer by accident.

In another terminal
athena.cmd status

shows whether it is recording, what it has cost in processor time and disk since it started, and who has a key.

3

Open your page

An icon with two circles appears near the clock. Click it, or run this, and your browser opens a page that only you can reach (Chapter 7):

athena.cmd open

The page shows the last hour as an agent would be given it, who has a key, anything waiting for your yes, what is held about you, and the log. Everything in the steps below can be done there; the commands are given because they are easier to copy.

Add your mail and calendar (optional)

Athena can read a Google account's mail and calendar with a right to read and nothing more (Chapter 8). Google first has to know which program is asking, and for a program you run yourself you make that registration: in Google Cloud Console, create a project, switch on the Gmail API and the Google Calendar API, set up the consent screen as External and add yourself as a test user, and create an OAuth client of type Desktop app. While the consent screen is in "testing" a sign-in lapses after seven days; to make it last, publish it, for which Google asks for a home page and a privacy policy link on its branding page. Download its JSON, then:

athena.cmd account client path\to\downloaded.json
athena.cmd account add google

Your browser opens Google's own sign-in page. Athena never sees your password. athena.cmd account lists what is signed in and what was read; athena.cmd account remove you@example.com --forget signs out and deletes what was read.

Tell it what never to record

Password managers, banks, brokerages, sign-in pages and private browser windows are excluded from the start (Chapter 3). Add your own:

athena.cmd exclude app signal*
athena.cmd exclude site *.clinic.example
athena.cmd exclude title "payroll"

A running recorder picks an addition up within half a minute. What you add is joined to the built-in list and cannot shorten it. The other controls:

athena.cmd pause 30        stop recording for thirty minutes
athena.cmd resume
athena.cmd forget 10       delete what was recorded in the last ten minutes

Then open me.md in the data folder and write, in your own words, anything your agents should know about you. It is the one file the program never changes, and what is in it is served marked as stated by you.

4

See what an agent would get

athena.cmd ask get_recent_activity "{\"minutes\": 60}"
athena.cmd ask search_activity "{\"query\": \"the bill that did not add up\"}"

This calls a tool as the owner and prints exactly what a client with every scope would receive: the notice, each item, and its provenance. Read one answer through before you let anything else in.

5

Give an agent a key

For a known agent, one command makes its key and prints exactly what to give it:

athena.cmd connect claude-code
athena.cmd connect cursor
athena.cmd connect claude-desktop

The kinds are claude-code, claude-desktop, cursor, vscode, codex (which the ChatGPT desktop app shares), gemini, devin, stdio for any agent that starts a command, and other for any agent that calls an address. For anything else, by hand:

athena.cmd grant myagent --scopes now,history,profile

The token is shown once; only its hash is kept. The agent sends it as Authorization: Bearer ... to the address above, as a Streamable HTTP server of the Model Context Protocol. The five scopes are now (the last three hours), history, profile, writing (what you typed) and screen_text (what was on your screen). Start without the last two.

For a visitor you trust less:

athena.cmd grant visitor --scopes now --mode ask
athena.cmd requests
athena.cmd approve 3fa9c1

Every request from that client waits for your approval, which is good for that one request, once, and lapses in ten minutes. athena.cmd audit lists what each client asked for and was given, and athena.cmd revoke myagent ends a key at once (Chapter 6).

6

Optional: the model pass

Goals, priorities, preferences, commitments and style need a language model (Chapter 5). Put this in config.json in the data folder and your key in the environment as ATHENA_ANTHROPIC_API_KEY:

{"model": {"provider": "anthropic", "name": "claude-haiku-5-5"}}

or, for a model on your own machine, {"model": {"provider": "ollama", "name": "a model you have"}}. Then athena.cmd distil --model runs it once, and after that it runs by itself at most every six hours when there is new evidence. The model is shown what you did and what you typed, never what was on your screen. Not tested: the pass has been run against a pretend model only.

7

Optional: the classifier

To withhold more of the text that is written to steer an agent, at the price of about 1 GB of memory and 740 MB of disk:

{"search": {"guard_model": "protectai/deberta-v3-base-prompt-injection-v2"}}

With it on, a piece of someone else's text that has not been checked yet is withheld, not served, and is checked in the background (Chapter 4).

Checking your own copy

%USERPROFILE%\.athena\venv\Scripts\python -m pytest
%USERPROFILE%\.athena\venv\Scripts\python -m evals.run

The first runs the 141 tests. The second scores search, the privacy rules and the attribution of typed text on a made-up fortnight and prints quality beside cost (Chapter 9).

Every factual claim on this site carries an evidence grade, and anything not yet run is marked as such.
